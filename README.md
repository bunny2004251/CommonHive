# COMMONHIVE app

## Quick start
- Open `index.html` in a modern browser to try the app.
- For installable PWA behavior, serve this folder from an HTTPS website (or localhost).
- Visit the hosted address in Chrome/Edge/Safari and choose **Install app** / **Add to Home Screen**.

## Notes
- The app's existing interface and client-side logic are preserved.
- The app stores its prototype data in this browser's local storage. Data is local to the browser/device and is not automatically synced between users.
- PWA offline caching is enabled after the first successful visit.
- This package does not include a hosted backend, authentication service, or multi-user database.
